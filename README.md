# A simple lua love2d top down pixel game template

**To run this game:**

- Clone or this repository, or download it as a zipfile
- Install love2d game engine (https://love2d.org/)
- Install the libraries used, and put them in the same folder of love2d framework
- Libraries used:
- https://github.com/kikito/anim8
- https://github.com/vrld/hump
- https://github.com/karai17/Simple-Tiled-Implementation
- https://github.com/a327ex/windfield
- Download aseprite as well to edit the test-maps.lua (Optional)
- https://www.mapeditor.org/
- Now go outside the directory, and run love _directory-name/_ on your terminal
- For windows drag, and the main.lua file to the love2d icon on your desktop
